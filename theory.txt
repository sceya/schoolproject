        <h2 class="section-title" id="section1">Степень с рациональным показателем</h2>

        <h3 class="subsection-title">1.1. Основа: корень n-й степени</h3>
        <p class="theory-text">Прежде чем говорить о дробных показателях, нужно чётко понимать, что такое корень.</p>
        <p class="theory-text">Корень n-й степени из числа a — это такое число b, которое при возведении в степень n даёт a. Записывается как n√a. Здесь n называют показателем корня, a — подкоренным выражением.</p>
        <p class="theory-text">Важно различать две ситуации:</p>
        <p class="theory-text">Если n нечётное (3, 5, 7 и так далее), то корень можно извлечь из любого числа. Положительного — будет положительный, отрицательного — будет отрицательный. Например, корень кубический из минус восьми равен минус двум, потому что минус два в кубе даёт минус восемь.</p>
        <p class="theory-text">Если n чётное (2, 4, 6 и так далее), то под корнем должно стоять неотрицательное число. Из минуса извлечь корень чётной степени нельзя, если мы работаем с действительными числами. Корень из положительного числа тоже положителен. Например, квадратный корень из 25 равен 5, но не минус 5, потому что арифметический корень всегда неотрицателен</p>
        <p class="theory-text">Отсюда правило: для чётных n подкоренное выражение должно быть больше или равно нулю, для нечётных — любое.</p>
        <p class="theory-text">Этот момент часто упускают, а потом получают ошибки в примерах с переменными.</p>

                <p class="theory-text">Показатель корня нечётный, поэтому никаких ограничений на знак подкоренного выражения нет. Всё просто.</p>

                <p class="theory-text">Корень четвёртой степени из 81. Вспоминаем: 3 в четвёртой степени равно 81. Значит, корень из 81 равен 3.</p>

            <p class="task-level">Уровень 3. Повышенный с переменной</p>
            <p class="theory-text"><strong>Задание:</strong> Упростить выражение: корень шестой степени из 64x в двенадцатой степени, при условии что x может быть любым действительным числом.</p>
            <div class="solution hidden" id="solution3">
                <p class="theory-text"><strong>Решение:</strong></p>
                <p class="theory-text">Показатель корня равен 6, это чётное число. Значит, результат извлечения корня должен быть неотрицательным, независимо от знака x.</p>
                <p class="theory-text">Разбираем выражение по частям. Сначала число 64. 64 это 2 в шестой степени. Корень шестой степени из 2 в шестой равен 2.</p>
                <p class="theory-text">Теперь переменная часть: x в двенадцатой степени под корнем шестой степени. Применяем запись через дробный показатель. Корень шестой степени из x в двенадцатой равен x в степени 12/6, то есть x в квадрате.</p>
                <p class="theory-text">Но здесь важен момент с чётным показателем корня. x в квадрате всегда неотрицательно, даже если сам x отрицательный. Поэтому ответ будет просто x в квадрате, без модуля, потому что квадрат уже гарантирует неотрицательность.</p>
                <p class="theory-text">Собираем вместе: 2 умножить на x в квадрате.</p>
                <p class="theory-text">Если бы в условии был корень шестой степени из x в шестой, мы обязаны были бы поставить модуль: ответ был бы модуль x. А здесь степень под корнем чётная и большая, поэтому всё обходится без модуля.</p>
                <p class="theory-text"><strong>Ответ: 2x в квадрате.</strong></p>
            </div>

        <h3 class="subsection-title">1.2. Дробная степень</h3>
        <p class="theory-text">Теперь связываем корни и степени. Любой корень можно записать как степень с дробным показателем.</p>
        <p class="theory-text">Формула такая: a в степени m/n равно корню n-й степени из a в степени m. Показатель корня n уходит в знаменатель дроби, а степень подкоренного выражения m — в числитель.</p>
        <p class="theory-text">Простой пример: a в степени 1/2 — это квадратный корень из a. А a в степени 1/3 — кубический корень. Если в числителе не единица, а другое число, то мы сначала возводим в эту степень, а потом извлекаем корень, или наоборот — порядок не важен, если основание положительное.</p>
        <p class="theory-text">Главное ограничение вытекает из свойств корней. Если знаменатель дроби чётный, основание должно быть неотрицательным. Если знаменатель нечётный, ограничений нет.</p>
        <p class="theory-text">Например, выражение (минус 8) в степени 1/3 имеет смысл и равно минус двум. А вот (минус 4) в степени 1/2 смысла не имеет, потому что квадратный корень из отрицательного числа не извлекается.</p>

        <h3 class="subsection-title">1.3. Все свойства степеней</h3>
        <p class="theory-text">Все привычные правила степеней остаются в силе и для дробных показателей. Вот они:</p>
        <p class="theory-text">При умножении степеней с одинаковым основанием показатели складываются.</p>
        <p class="theory-text">При делении — показатели вычитаются.</p>
        <p class="theory-text">При возведении степени в степень — показатели перемножаются.</p>
        <p class="theory-text">Степень произведения равна произведению степеней.</p>
        <p class="theory-text">Степень частного равна частному степеней.</p>
        <p class="theory-text">Важно только помнить про область допустимых значений. Если в примере появляется чётный корень, основание не должно быть отрицательным. Если этого не отследить, можно получить выражение, которое не имеет смысла, или потерять корни уравнения.</p>
        <p class="theory-text">Эти пять свойств — основной рабочий инструмент. Ими придётся пользоваться постоянно, что в простых вычислениях, что при решении серьёзных уравнений.</p>

        <div class="task-block">
            <p class="task-level">Уровень 1. Базовый (умножение степеней)</p>
            <p class="theory-text"><strong>Задание:</strong> Упростить \(a^{\frac{1}{2}} \cdot a^{\frac{1}{3}}\).</p>
            <div class="solution hidden" id="solution7">
                <p class="theory-text"><strong>Решение:</strong></p>
                <p class="theory-text">При умножении степеней с одинаковым основанием показатели складываются. Складываем дроби:</p>
                <p class="theory-text">\(\dfrac{1}{2} + \dfrac{1}{3} = \dfrac{3}{6} + \dfrac{2}{6} = \dfrac{5}{6}\)</p>
                <p class="theory-text">Получаем \(a^{\frac{5}{6}}\), или \(\sqrt[6]{a^5}\).</p>
                <p class="theory-text"><strong>Ответ: \(a^{\frac{5}{6}}\).</strong></p>
            </div>
            <button class="reveal-btn" onclick="toggleSolution('solution7', this)">узнать решение и ответ</button>

            <p class="task-level">Уровень 2. Средний (деление и возведение в степень)</p>
            <p class="theory-text"><strong>Задание:</strong> Упростить \(\dfrac{b^{\frac{3}{4}}}{b^{\frac{1}{2}}}\) и результат возвести в квадрат.</p>
            <div class="solution hidden" id="solution8">
                <p class="theory-text"><strong>Решение:</strong></p>
                <p class="theory-text">Сначала деление. При делении показатели вычитаются:</p>
                <p class="theory-text">\(\dfrac{3}{4} - \dfrac{1}{2} = \dfrac{3}{4} - \dfrac{2}{4} = \dfrac{1}{4}\)</p>
                <p class="theory-text">Получили \(b^{\frac{1}{4}}\). Теперь возводим в квадрат, то есть в степень 2. Показатели перемножаются:</p>
                <p class="theory-text">\(b^{\frac{1}{4} \cdot 2} = b^{\frac{2}{4}} = b^{\frac{1}{2}}\)</p>
                <p class="theory-text"><strong>Ответ: \(b^{\frac{1}{2}}\) или \(\sqrt{b}\).</strong></p>
            </div>
            <button class="reveal-btn" onclick="toggleSolution('solution8', this)">узнать решение и ответ</button>

        <div class="task-block">
            <p class="task-level">Уровень 3. Повышенный (все свойства вместе)</p>
            <p class="theory-text"><strong>Задание:</strong> Упростить \(\dfrac{(x^{\frac{2}{3}} \cdot y^{-\frac{1}{2}})^6}{x^3 \cdot y^{-2}}\).</p>
            <div class="solution hidden" id="solution9">
                <p class="theory-text"><strong>Решение:</strong></p>
                <p class="theory-text">Сначала числитель. Возводим произведение в степень 6, умножая показатели:</p>
                <p class="theory-text">\(x^{\frac{2}{3} \cdot 6} = x^4\)</p>
                <p class="theory-text">\(y^{-\frac{1}{2} \cdot 6} = y^{-3}\)</p>
                <p class="theory-text">Числитель стал \(x^4 \cdot y^{-3}\).</p>
                <p class="theory-text">Теперь деление на знаменатель \(x^3 \cdot y^{-2}\). Вычитаем показатели:</p>
                <p class="theory-text">Для x: \(4 - 3 = 1\), остаётся \(x^1\).</p>
                <p class="theory-text">Для y: \(-3 - (-2) = -3 + 2 = -1\), остаётся \(y^{-1}\).</p>
                <p class="theory-text">Получаем \(x \cdot y^{-1}\), или \(\dfrac{x}{y}\).</p>
                <p class="theory-text"><strong>Ответ: \(\dfrac{x}{y}\).</strong></p>
            </div>

        <h2 class="section-title" id="section2">Степень с действительным показателем</h2>

        <h3 class="subsection-title">2.1. Смысл иррационального показателя</h3>
        <p class="theory-text">Есть числа, которые нельзя записать дробью. Корень из двух, число пи, число е — у них бесконечный хвост после запятой без повторений. Это иррациональные числа. Как понимать степень, где в показателе такое число? Старый способ через корень здесь не подходит, потому что иррациональное число не превратить в m/n.</p>
        <p class="theory-text">Идея простая: любое иррациональное число можно приблизить рациональным. С любой точностью. Например, корень из двух это примерно 1,4. Точнее — 1,41. Ещё точнее — 1,414. И так далее. На каждом шаге мы получаем обычную дробь, а с дробным показателем мы работать умеем. Чем точнее приближение, тем ближе ответ к истинному значению. В пределе, на бесконечном шаге уточнения, мы и получаем степень с иррациональным показателем.</p>

        <h3 class="subsection-title">2.2. Определение через предел</h3>
        <p class="theory-text">Формально говорят так: степень с иррациональным показателем — это предел последовательности степеней с рациональными показателями, которые приближаются к данному иррациональному числу.</p>
        <p class="theory-text">На практике мы никогда не считаем бесконечную последовательность. Берём достаточно точное приближение и вычисляем с ним. Например, 2 в степени корень из двух примерно равно 2 в степени 1,4142. Этого хватает для любой прикладной задачи.</p>

        <h3 class="subsection-title">2.3. Единое правило</h3>
        <p class="theory-text">Как только показатель становится любым действительным числом, основание обязано быть строго больше нуля. Отрицательные основания под действительный показатель не подставляют. Причина в том, что при приближении иррационального показателя разными дробями ответы начнут прыгать, и однозначного значения не получится.</p>
        <p class="theory-text">Ноль тоже не годится как основание. Ноль в положительной степени — ноль, но ноль в отрицательной уже не существует. Для общности считают, что основание всегда положительное и не равно единице, если мы говорим о функции.</p>
        <p class="theory-text">Все пять свойств степеней работают без изменений и для действительных показателей. Отдельно запоминать ничего не нужно. Достаточно соблюдать требование: основание больше нуля.</p>

        <h2 class="section-title" id="section3">Показательная функция</h2>

        <h3 class="subsection-title">3.1. Вид и область определения</h3>
        <p class="theory-text">Общий вид: y = a в степени x. Здесь a — основание, x — показатель, теперь он переменная. Основание a должно быть больше нуля и не равно единице. Если a равно единице, то функция вырождается в прямую линию y = 1, это неинтересно.</p>
        <p class="theory-text">Область определения — все действительные числа. x может быть любым: целым, дробным, иррациональным, положительным, отрицательным, нулём. Ограничений нет. Область значений — только положительные числа. Ноль и отрицательные числа функция никогда не выдаст, сколько бы мы ни подставляли x. Это прямое следствие того, что положительное основание в любой степени даёт положительный результат.</p>

        <h3 class="subsection-title">3.2. Характер монотонности</h3>
        <p class="theory-text">Поведение функции полностью зависит от основания. Есть два варианта.</p>
        <p class="theory-text">Первый: a больше единицы. Тогда функция растёт на всей области определения. Чем больше x, тем больше y. График идёт слева вверх. При x, стремящемся к минус бесконечности, график прижимается к оси X, но не пересекает её. При x равном нулю значение равно единице. При x, стремящемся к плюс бесконечности, график резко уходит вверх.</p>
        <p class="theory-text">Второй: a между нулём и единицей. Тогда функция убывает. Чем больше x, тем меньше y. График идёт слева вниз. При x, стремящемся к минус бесконечности, график уходит вверх. При x равном нулю по-прежнему единица. При x, стремящемся к плюс бесконечности, график прижимается к оси X.</p>
        <p class="theory-text">В обоих случаях ось X является горизонтальной асимптотой. График подходит к ней бесконечно близко, но никогда не касается.</p>
        <p class="theory-text">Эти два варианта поведения важно запомнить, потому что на них строится решение показательных неравенств. Когда основание больше единицы, знак неравенства сохраняется. Когда основание меньше единицы, знак меняется на противоположный. Об этом подробно поговорим в следующем разделе.</p>

        <h2 class="section-title" id="section4">Техника решений</h2>

        <h3 class="subsection-title">4.1. Показательные уравнения</h3>
        <p class="theory-text">Уравнение называется показательным, если переменная стоит в показателе степени. Главный принцип решения — привести обе части к одному основанию. Если основания одинаковые и они положительные, приравниваем показатели.</p>
        <p class="theory-text">Первый приём: приведение к одному основанию. Все числа стараемся записать как степень одного и того же числа. Например, 4 это 2 в квадрате, 8 это 2 в кубе, 1/2 это 2 в минус первой. После такой замены получаем равенство степеней с одинаковым основанием, дальше работаем только с показателями.</p>
        <p class="theory-text">Второй приём: вынесение общего множителя. Если в уравнении есть сумма или разность степеней с одинаковым основанием, можно вынести степень с наименьшим показателем за скобки. В скобках останется число, и уравнение упростится до обычного линейного или дробного.</p>
        <p class="theory-text">Третий приём: замена переменной. Если в уравнении встречается одна и та же степень, но в разных формах, делают замену. Например, видим 2 в степени x и 4 в степени x. Замечаем, что 4 в степени x это 2 в степени 2x, то есть квадрат 2 в степени x. Обозначаем 2 в степени x за t, решаем квадратное уравнение, а потом возвращаемся к исходной переменной. Важный момент: t всегда больше нуля, потому что положительное основание в любой степени даёт положительный результат. Если получили отрицательный корень для t, он не подходит.</p>

        <div class="task-block">
            <p class="task-level">Уровень 1. Базовый (приведение к одному основанию)</p>
            <p class="theory-text"><strong>Задание:</strong> Решить уравнение \(3^{x-1} = 27\).</p>
            <div class="solution hidden" id="solution22">
                <p class="theory-text"><strong>Решение:</strong></p>
                <p class="theory-text">Замечаем, что \(27 = 3^3\). Переписываем уравнение:</p>
                <p class="theory-text">\(3^{x-1} = 3^3\)</p>
                <p class="theory-text">Основания одинаковые и больше нуля, значит, показатели равны:</p>
                <p class="theory-text">\(x - 1 = 3\)</p>
                <p class="theory-text">\(x = 4\)</p>
                <p class="theory-text"><strong>Ответ: \(x = 4\).</strong></p>
            </div>

            <p class="theory-text"><strong>Задание:</strong> Решить уравнение \(2^{x+1} + 2^x = 24\).</p>
            <div class="solution hidden" id="solution23">
                <p class="theory-text"><strong>Решение:</strong></p>
                <p class="theory-text">Раскладываем первое слагаемое: \(2^{x+1} = 2 \cdot 2^x\). Подставляем:</p>
                <p class="theory-text">\(2 \cdot 2^x + 2^x = 24\)</p>
                <p class="theory-text">Выносим \(2^x\) за скобки:</p>
                <p class="theory-text">\(2^x(2 + 1) = 24\)</p>
                <p class="theory-text">\(2^x \cdot 3 = 24\)</p>
                <p class="theory-text">Делим обе части на 3:</p>
                <p class="theory-text">\(2^x = 8\)</p>
                <p class="theory-text">\(2^x = 2^3\), значит, \(x = 3\).</p>
                <p class="theory-text"><strong>Ответ: \(x = 3\).</strong></p>
            </div>

        <div class="task-block">
            <p class="task-level">Уровень 3. Повышенный (замена переменной)</p>
            <p class="theory-text"><strong>Задание:</strong> Решить уравнение \(9^x - 4 \cdot 3^x + 3 = 0\).</p>
            <div class="solution hidden" id="solution24">
                <p class="theory-text"><strong>Решение:</strong></p>
                <p class="theory-text">Замечаем, что \(9^x = (3^2)^x = (3^x)^2\). Обозначим \(3^x = t\), при этом \(t > 0\), так как положительное основание в любой степени даёт положительный результат.</p>
                <p class="theory-text">Подставляем:</p>
                <p class="theory-text">\(t^2 - 4t + 3 = 0\)</p>
                <p class="theory-text">Решаем квадратное уравнение. Дискриминант: \(D = 16 - 12 = 4\). Корни:</p>
                <p class="theory-text">\(t_1 = \dfrac{4 - 2}{2} = 1\)</p>
                <p class="theory-text">\(t_2 = \dfrac{4 + 2}{2} = 3\)</p>
                <p class="theory-text">Оба корня положительные, оба подходят. Возвращаемся к замене:</p>
                <p class="theory-text">\(3^x = 1\), значит, \(x = 0\).</p>
                <p class="theory-text">\(3^x = 3\), значит, \(x = 1\).</p>
                <p class="theory-text"><strong>Ответ: \(x = 0\) и \(x = 1\).</strong></p>
            </div>

        <h3 class="subsection-title">4.2. Показательные неравенства</h3>
        <p class="theory-text">Принцип тот же: приводим к одному основанию. Но появляется важный нюанс со знаком неравенства.</p>
        <p class="theory-text">Если основание больше единицы, то функция возрастает. Значит, большему значению функции соответствует больший показатель. Знак неравенства сохраняется.</p>
        <p class="theory-text">Если основание между нулём и единицей, функция убывает. Значит, большему значению функции соответствует меньший показатель. Знак неравенства меняется на противоположный.</p>
        <p class="theory-text">Поэтому при решении всегда смотрим на основание. Привёл к одному основанию, определил, больше оно единицы или меньше, и только потом переписываешь неравенство для показателей.</p>

        <div class="task-block">
            <p class="task-level">Уровень 1. Базовый (основание больше единицы)</p>
            <p class="theory-text"><strong>Задание:</strong> Решить неравенство \(2^x > 8\).</p>
            <div class="solution hidden" id="solution19">
                <p class="theory-text"><strong>Решение:</strong></p>
                <p class="theory-text">Приводим правую часть к основанию 2. Так как \(8 = 2^3\), получаем:</p>
                <p class="theory-text">\(2^x > 2^3\)</p>
                <p class="theory-text">Основание 2 больше единицы, функция возрастает. Значит, большему значению функции соответствует больший показатель. Знак неравенства сохраняется:</p>
                <p class="theory-text">\(x > 3\)</p>
                <p class="theory-text"><strong>Ответ: \(x \in (3; +\infty)\).</strong></p>
            </div>
            <button class="reveal-btn" onclick="toggleSolution('solution19', this)">узнать решение и ответ</button>
        </div>

        <div class="task-block">
            <p class="task-level">Уровень 2. Средний (основание меньше единицы)</p>
            <p class="theory-text"><strong>Задание:</strong> Решить неравенство \(\left(\dfrac{1}{3}\right)^x \leq \dfrac{1}{9}\).</p>
            <div class="solution hidden" id="solution20">
                <p class="theory-text"><strong>Решение:</strong></p>
                <p class="theory-text">Замечаем, что \(\dfrac{1}{9} = \left(\dfrac{1}{3}\right)^2\). Переписываем:</p>
                <p class="theory-text">\(\left(\dfrac{1}{3}\right)^x \leq \left(\dfrac{1}{3}\right)^2\)</p>
                <p class="theory-text">Основание \(\dfrac{1}{3}\) меньше единицы, функция убывает. Большему значению функции соответствует меньший показатель. Поэтому при переходе к показателям знак неравенства меняется на противоположный:</p>
                <p class="theory-text">\(x \geq 2\)</p>
                <p class="theory-text"><strong>Ответ: \(x \in [2; +\infty)\).</strong></p>
            </div>

        <div class="task-block">
            <p class="task-level">Уровень 3. Повышенный (разные основания)</p>
            <p class="theory-text"><strong>Задание:</strong> Решить неравенство \(5^{x+1} \leq 25 \cdot \left(\dfrac{1}{5}\right)^x\).</p>
            <div class="solution hidden" id="solution21">
                <p class="theory-text"><strong>Решение:</strong></p>
                <p class="theory-text">Приводим всё к одному основанию. Число 25 это \(5^2\). Дробь \(\dfrac{1}{5}\) это \(5^{-1}\). Переписываем правую часть:</p>
                <p class="theory-text">\(25 \cdot \left(\dfrac{1}{5}\right)^x = 5^2 \cdot (5^{-1})^x = 5^2 \cdot 5^{-x} = 5^{2 - x}\)</p>
                <p class="theory-text">Теперь неравенство выглядит так:</p>
                <p class="theory-text">\(5^{x+1} \leq 5^{2 - x}\)</p>
                <p class="theory-text">Основание 5 больше единицы, функция возрастает. Знак сохраняется:</p>
                <p class="theory-text">\(x + 1 \leq 2 - x\)</p>
                <p class="theory-text">Переносим x в левую часть, числа в правую:</p>
                <p class="theory-text">\(x + x \leq 2 - 1\)</p>
                <p class="theory-text">\(2x \leq 1\)</p>
                <p class="theory-text">\(x \leq 0{,}5\)</p>
                <p class="theory-text"><strong>Ответ: \(x \in (-\infty; 0{,}5]\).</strong></p>
            </div>

        <h3 class="subsection-title">4.3. Преобразование выражений</h3>
        <p class="theory-text">Часто задача не в том, чтобы решить уравнение, а чтобы упростить громоздкое выражение со степенями и корнями. Здесь работают те же пять свойств степеней.</p>
        <p class="theory-text">Главный совет: все корни записывай как степени с дробным показателем. После этого любые преобразования сводятся к сложению, вычитанию и умножению дробей в показателях. Это проще, чем путаться в свойствах корней.</p>
        <p class="theory-text">Второй совет: все составные основания раскладывай на простые. Например, 6 это 2 умножить на 3, 12 это 2 в квадрате умножить на 3. После этого применяешь свойство степени произведения и работаешь отдельно с каждой переменной.</p>

        <div class="task-block">
            <p class="task-level">Уровень 1. Базовый</p>
            <p class="theory-text"><strong>Задание:</strong> Упростить \(\sqrt[3]{a} \cdot \sqrt{a}\).</p>
            <div class="solution hidden" id="solution16">
                <p class="theory-text"><strong>Решение:</strong></p>
                <p class="theory-text">Переводим корни в дробные показатели. Кубический корень — это степень \(\frac{1}{3}\), квадратный корень — степень \(\frac{1}{2}\):</p>
                <p class="theory-text">\(a^{\frac{1}{3}} \cdot a^{\frac{1}{2}}\)</p>
                <p class="theory-text">Основание одинаковое, показатели складываем:</p>
                <p class="theory-text">\(\dfrac{1}{3} + \dfrac{1}{2} = \dfrac{2}{6} + \dfrac{3}{6} = \dfrac{5}{6}\)</p>
                <p class="theory-text"><strong>Ответ: \(a^{\frac{5}{6}}\) или \(\sqrt[6]{a^5}\).</strong></p>
            </div>

            <p class="task-level">Уровень 2. Средний</p>
            <p class="theory-text"><strong>Задание:</strong> Упростить \(\dfrac{b \cdot \sqrt[4]{b^3}}{\sqrt{b}}\).</p>
            <div class="solution hidden" id="solution17">
                <p class="theory-text"><strong>Решение:</strong></p>
                <p class="theory-text">Переводим все элементы в степени. Число \(b\) в числителе — это \(b^1\). Корень четвёртой степени из \(b^3\) — это \(b^{\frac{3}{4}}\). Квадратный корень в знаменателе — это \(b^{\frac{1}{2}}\).</p>
                <p class="theory-text">Числитель: \(b^1 \cdot b^{\frac{3}{4}} = b^{1 + \frac{3}{4}} = b^{\frac{7}{4}}\).</p>
                <p class="theory-text">Теперь деление на знаменатель:</p>
                <p class="theory-text">\(\dfrac{b^{\frac{7}{4}}}{b^{\frac{1}{2}}} = b^{\frac{7}{4} - \frac{1}{2}} = b^{\frac{7}{4} - \frac{2}{4}} = b^{\frac{5}{4}}\)</p>
                <p class="theory-text"><strong>Ответ: \(b^{\frac{5}{4}}\) или \(b \cdot \sqrt[4]{b}\).</strong></p>
            </div>

        <div class="task-block">
            <p class="task-level">Уровень 3. Повышенный</p>
            <p class="theory-text"><strong>Задание:</strong> Упростить \(\sqrt{\dfrac{27x^6}{y^3}} \cdot y^{\frac{1}{2}}\).</p>
            <div class="solution hidden" id="solution18">
                <p class="theory-text"><strong>Решение:</strong></p>
                <p class="theory-text">Сначала работаем с корнем. Квадратный корень — это степень \(\frac{1}{2}\). Применяем её ко всей дроби:</p>
                <p class="theory-text">\(\left(\dfrac{27x^6}{y^3}\right)^{\frac{1}{2}}\)</p>
                <p class="theory-text">Раскладываем 27 как \(3^3\):</p>
                <p class="theory-text">\(\left(\dfrac{3^3 \cdot x^6}{y^3}\right)^{\frac{1}{2}}\)</p>
                <p class="theory-text">Возводим каждый множитель в степень \(\frac{1}{2}\):</p>
                <p class="theory-text">\(3^{\frac{3}{2}} \cdot x^{\frac{6}{2}} \cdot y^{-\frac{3}{2}} = 3^{\frac{3}{2}} \cdot x^3 \cdot y^{-\frac{3}{2}}\)</p>
                <p class="theory-text">Теперь умножаем на \(y^{\frac{1}{2}}\) из условия:</p>
                <p class="theory-text">\(3^{\frac{3}{2}} \cdot x^3 \cdot y^{-\frac{3}{2}} \cdot y^{\frac{1}{2}} = 3^{\frac{3}{2}} \cdot x^3 \cdot y^{-\frac{3}{2} + \frac{1}{2}} = 3^{\frac{3}{2}} \cdot x^3 \cdot y^{-1}\)</p>
                <p class="theory-text">\(3^{\frac{3}{2}}\) можно записать как \(3 \cdot \sqrt{3}\), а \(y^{-1}\) как \(\frac{1}{y}\). Получаем:</p>
                <p class="theory-text">\(\dfrac{3\sqrt{3} \cdot x^3}{y}\)</p>
                <p class="theory-text"><strong>Ответ: \(\dfrac{3\sqrt{3} \, x^3}{y}\).</strong></p>
            </div>

        function updateHeartPosition() {
            const scrollTop = window.pageYOffset || document.documentElement.scrollTop;
            const docHeight = document.documentElement.scrollHeight - window.innerHeight;
            const scrollPercent = Math.min(scrollTop / (docHeight || 1), 1);
            const trackHeight = scrollTrack.clientHeight;
            const heartHeight = scrollHeart.clientHeight;
            const maxTop = trackHeight - heartHeight;
            scrollHeart.style.top = (scrollPercent * maxTop) + 'px';
        }

        window.addEventListener('scroll', updateHeartPosition);
        window.addEventListener('resize', updateHeartPosition);
        updateHeartPosition();

        scrollToTopBtn.addEventListener('click', function() {
            window.scrollTo({ top: 0, behavior: 'smooth' });
        });

        function toggleSolution(id, btn) {
            const solution = document.getElementById(id);
            if (solution.classList.contains('hidden')) {
                solution.classList.remove('hidden');
                solution.classList.add('visible');
                btn.textContent = 'скрыть решение и ответ';
            } else {
                solution.classList.remove('visible');
                solution.classList.add('hidden');
                btn.textContent = 'узнать решение и ответ';
            }
        }

        let heartTimeout;
        const hearts = [];
        document.addEventListener('mousemove', function(e) {
            if (heartTimeout) return;
            heartTimeout = setTimeout(() => { heartTimeout = null; }, 80);
            const heart = document.createElement('div');
            heart.className = 'cursor-heart';
            heart.style.left = (e.clientX - 3) + 'px';
            heart.style.top = (e.clientY - 4) + 'px';
            const size = 4 + Math.random() * 6;
            heart.style.width = size + 'px';
            heart.style.height = size + 'px';
            document.body.appendChild(heart);
            hearts.push(heart);
            heart.addEventListener('animationend', function() {
                heart.remove();
                const idx = hearts.indexOf(heart);
                if (idx > -1) hearts.splice(idx, 1);
            });
            if (hearts.length > 30) {
                const old = hearts.shift();
                old.remove();
            }
        });
